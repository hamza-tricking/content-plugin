# Strategy, learning plan, publishing support, closed loop

Show the patience note (see `content-agent` skill) before each grilling round. Ask the whole frontier per round, numbered, with your recommended answer. Write each result to `strategy/` and ask the user to confirm.

## Phase 4: strategy (`strategy/pillars.md`, `strategy/calendar.md`)
Decide with the user:
- **Angle:** what the creator wants ∩ what the audience asks ∩ what nobody covers. A personal-experience angle usually differentiates when the topic itself is crowded.
- **Pattern portfolio:** several repeatable success patterns, each needing a fresh idea (never one rigid rule). Shares are guesses until measured; judge each pattern after about 10 videos: median views first, then skip rate, then comments.
- **Posting guide:** volume the user believes in, times from the user's own analytics (rough guide, the user decides how each video is made).
- **Hook rules:** defaults the user can break; test against skip rate.
- **Conversion route:** only what the user wants now. Followers first; do not push lists, communities or sales before the user wants them.
- **Targets:** the user's numbers, reviewed at day 30. Do not invent targets as facts.
- **Keyword calls to action:** a registry `strategy/keywords.md` (keyword, video, resource, platform). Use automation only where the platform allows it; otherwise manual replies.
- **Inspiration rule** and **off-limits** from the DNA.

## Phase 5: learning plan (`strategy/learning-plan.md`)
Pick the weakest measured skill (often the hook). Learn by practice: one test style per week, read the numbers, 3 lines on what worked. No paid courses unless the user's budget allows. Daily time cap from the interview. Do not teach editing or production unless the optional module is on.

## Phase 6: publishing support
Ask how the user posts (manual or scheduled; some users find scheduling lowers quality, so never assume). The agent prepares per video, when asked: caption and hashtags in the user's voice, the keyword and its resource, a suggested slot as a guide, the pattern label and hook line for the learning log. The agent never posts or schedules without an explicit yes.

## Phase 7: closed loop (`strategy/closed-loop.md`)
- Sources: only what the user has set up.
- Weekly review on request (`/content-agent:review`): 3 lines (new followers, median views per pattern, skip rate, best and worst video). Deeper review at day 30.
- Propose strategy changes only with evidence and enough videos; the user always decides.
- No automatic reminders unless the user asks.

After each phase follow the `examples` skill.
