# Competitive landscape (phase 3)

Competitor analysis is an extra idea tool, not a rule for every video.

1. **Seeds:** ask the user for 5-10 accounts they follow or admire; add close accounts from the platform's "similar/suggested accounts" list via Claude in Chrome. Record followers, post count, funnel (community, course, agency, link in bio).
2. **Patterns:** look at 15-20 recent videos per account: median views vs followers, which videos beat the median, what their hooks have in common (number or price early, challenge or confession, on-screen text, visual change rhythm, structure, call to action). Treat results as hypotheses, not proof (small samples).
3. **Gap candidates:** list angles nobody seems to cover in the user's language and country. Verify each with a search on each platform (topic + local terms), noting who covers it. Search results often hide view counts: say that you know who covers it, not how well it performs.
4. **Other platforms:** check whether the same creators exist on the user's other platforms (match by handle and name, say it is unverified).
5. **Rank:** gaps as verified / plausible / unverified, with the evidence and its weakness.
6. Save to `vault/landscape/`, update `gaps.md`. The user confirms the ranking before phase 4.
7. Follow the `examples` skill at the end.
