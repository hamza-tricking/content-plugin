# content-agent

مساعد محتوى شخصي لصنّاع الفيديوهات القصيرة (Instagram / TikTok / Shorts): يحلّل حساباتك وجمهورك والمنافسين، يبني استراتيجية، ويعطيك أمثلة محتوى حقيقية. المحتوى فقط: التصوير والمونتاج والنشر بيدك.

A personal content agent for short-video creators. Content only: you keep control of filming, editing and posting.

## التثبيت في دقيقة / Install in one minute

افتح **Claude Code** والصق هذا السطر فقط:

```
Install the content-agent plugin by following the steps in https://github.com/hamza-tricking/content-plugin/blob/main/INSTALL.md
```

سيثبّته الذكاء الاصطناعي بنفسه ويقول لك الخطوة التالية (`/content-agent:start`).

Manual install (Claude Code 2.1.275+):

```
/plugin marketplace add hamza-tricking/content-plugin
/plugin install content-agent@content-plugin
```

## ماذا يفعل / What it does
Source check, your numbers, interview, competitors and gaps, strategy, learning plan, publishing support, weekly review, a visual data map, and worked example scripts. It never posts, sends or spends for you without an explicit yes. Everything it creates stays in your own folder.
